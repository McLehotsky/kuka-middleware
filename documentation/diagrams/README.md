# Úprava diagramov

Diagramy `1-ciele-a-stav.svg`, `*-realizacia.svg`, `5-datovy-model.svg`, `5-stavy-misie.svg`, `9.1-nasadenie.svg` a `9.6-ci-cd.svg` majú ručne rozvrhnutú grafiku. Vizuálne úpravy robte priamo v SVG a z neho exportujte príslušné PNG.

Príslušné súbory `.puml` zachytávajú štruktúru UML. Pri zmene toku upravte aj model. Náhľady z PlantUML ukladajte do samostatného priečinka, aby sa neprepísala ručná grafika.
