## Verification

Problems found during the Azure setup and their fixes (all in Azure, no code change):
- `Could not find a pool with name Defailt` – typo in the `AgentPoolName` variable.
- `Pipeline does not have permissions to use the referenced pool(s) Default` – the pool name is a `$(AgentPoolName)` macro, so Azure offers no Permit button; fixed in Agent pools > Default > Security > Pipeline permissions (already in `ci-cd/README.md`).
- `Pipeline Resource ci Input Must be Valid` / `Cannot determine pipeline run version` – the CI pipeline was named `McLehotsky.kuka-middleware-ci`; renamed to `kuka-middleware-ci`.

Runs:
- CI `#20261126.1` on main (f6b3637): green, 3 min 9 s, all backend and frontend tests passed; warning about `NodeTool@0`, replaced by `UseNode@1` in PR #11.
- CI on PR #11 (build 10/11): green, backend 36 s, frontend 49 s; no deprecation warning.
- CD `kuka-middleware-cd #20261126.1` on main (eec41b8, resource `ci/20261126.4`), manual: green, 2 min 2 s.
